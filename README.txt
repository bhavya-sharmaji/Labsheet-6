BCA111P - Lab Sheet 06
C++ Programs: Arrays, Sorting and Searching

This folder contains 20 separate C++ source files, numbered in the same order as the lab sheet.

How to run:
1. Open a .cpp file in Code::Blocks, Dev-C++, Visual Studio Code (with a C++ compiler), or another C++ IDE.
2. Compile and run the file.
3. Enter the values requested by the program.

Notes:
- Programs use simple loops and arrays for beginners.
- Binary Search programs require input already sorted in ascending order.
- Matrix programs use maximum dimensions of 10 x 10.
- Program 13 accepts one-word names; use underscores for names with spaces.
- Program 20 assumes a normally ascending-sorted array.

Each program is independent and should be compiled separately.
